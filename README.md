Sobre o projeto

O Music Player é um player de música para desktop desenvolvido com React e Electron.

A aplicação permite importar músicas armazenadas localmente, organizar uma biblioteca pessoal e reproduzir diferentes formatos de áudio diretamente pelo computador.

O projeto foi desenvolvido como uma experiência de estudo, explorando o desenvolvimento de aplicações desktop utilizando tecnologias web.

Status

Projeto arquivado.

O projeto não funciona mais como originalmente planejado devido às limitações atuais do Spotify e YouTube relacionadas ao download de músicas.

O desenvolvimento foi interrompido e o repositório permanece disponível como um projeto de estudo.
